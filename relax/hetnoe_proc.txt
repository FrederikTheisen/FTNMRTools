HetNOE processing with NMRPipe

Run from the original interleaved Bruker experiment folder.

1. In the experiment folder, run NMRPipe's `bruker` command to create
   `fid.com` from the Bruker `ser` data and acquisition parameters.
2. Run the generated conversion script:

       tcsh fid.com

   It writes the pseudo-3D NMRPipe FIDs under `fid/`.
3. Run the shared FTNMRTools processor:

       tcsh /path/to/FTNMRTools/relax/hetnoe_proc.com

The processor writes `hetnoe_processed/test%03d.ft3`. It follows the usual
NMRPipe H and 15N processing order and applies `POLY -auto -ord 4` while 15N
is active. Edit the H/N phases and baseline order at the top of the shared
`.com` script. Use the same phase settings for both planes.

No Python helper is required for this processing route. The Bruker-generated
`fid.com` supplies the experiment-specific conversion parameters.
